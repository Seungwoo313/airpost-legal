# airpost-legal

Airpost 앱의 지원 페이지와 정책 문서를 GitHub Pages로 호스팅하는 저장소.

**원본은 앱 저장소의 `docs/legal/`이다.** 정책이 바뀌면 세 곳을 같이 고친다 —
앱 저장소 `docs/legal/`, 앱 내 본문(`AirMail/LegalPapers.swift`), 그리고 이
저장소의 해당 페이지.
