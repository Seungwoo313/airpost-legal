# airpost-legal

Airpost 앱의 지원 페이지와 정책 문서를 GitHub Pages로 호스팅하는 저장소.

**원본은 앱 저장소의 `docs/legal/`이다.** 앱 저장소의
`tools/legal/build_site.py`가 앱 내 정책 본문과 이 저장소에 게시할 정적
HTML을 같은 원문에서 생성한다. 이 저장소에는 게시 결과물만 반영한다.

| 페이지 | 주소 |
| --- | --- |
| 지원(문의) | https://seungwoo313.github.io/airpost-legal/ |
| 개인정보처리방침 | https://seungwoo313.github.io/airpost-legal/privacy/ |
| Privacy Policy | https://seungwoo313.github.io/airpost-legal/privacy-en/ |
| 이용약관 | https://seungwoo313.github.io/airpost-legal/terms/ |
| Terms of Service | https://seungwoo313.github.io/airpost-legal/terms-en/ |

현재 게시본의 시행일은 2026-09-20이다. 이전 공개 문안은 Git 이력에서
확인할 수 있다.
